# PFO1 · Landing de portafolio personal

Landing page personal hecha con HTML y CSS (y un poco de JavaScript) que presenta mi perfil,
mis habilidades y una forma de contacto.

**Autora:** Florencia Lelis Guzmán
**GitHub:** [github.com/fguzman3026](https://github.com/fguzman3026)
**Demo publicada:** https://pfo-1-landing-page.vercel.app/

## Descripción

La landing tiene una sección de presentación (foto + texto), habilidades, una sección personal
a elección ("Fuera del código", sobre mis días libres y los videojuegos cooperativos), y un
formulario de contacto. Es de una sola página, con navegación por anclas.

Elegí una paleta oscura y minimalista. Usé Flexbox para organizar la sección de presentación y
Grid para las tarjetas de habilidades.

De animación hay solo una transición en los botones cuando se pasa el mouse.

El formulario de contacto es solo visual (no envía datos a ningún servidor); el único
JavaScript que usé evita que la página se recargue al enviarlo y muestra un mensaje de
confirmación simulado.

La foto de perfil es una foto propia, sin generar con IA.

## Declaración de uso de IA

Usé **Claude** (Anthropic), con un **plan pago (Pro)**, como asistente para desarrollar esta
landing.

Había usado herramientas de IA generativa antes, pero para cosas simples y puntuales, no para
páginas como esta.

Le expliqué la consigna completa (paso a paso, rúbrica y requisitos de uso de IA) y le pedí que
me ayudara a armar la estructura HTML, el CSS y el JavaScript básico del formulario. Primero me
propuso una versión más elaborada (con animaciones y una estética más armada); le pedí que la
simplificara, acorde a mi nivel real de HTML, CSS y JavaScript.

**Qué revisé y adapté con mi propio criterio:** verifiqué que la página cumpliera con todos los
requisitos técnicos de la consigna (etiquetas semánticas, Flexbox/Grid, Google Fonts,
responsive, alt en imágenes, labels en el formulario, enlace a GitHub). Escribí y ajusté yo
misma los textos de presentación, habilidades y la sección personal para que reflejen mi
situación real (estudiante de la tecnicatura, trabajo en la veterinaria, hobbies). También
reemplacé la imagen de placeholder por mi foto propia.

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, Grid, variables CSS, media queries)
- JavaScript básico (manejo del formulario)
- Google Fonts (Space Grotesk, Inter)
